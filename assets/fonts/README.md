# Fonts

All fonts are hosted here so the site loads nothing from third parties.

| File | Font | By | Licence |
|---|---|---|---|
| `soria.woff2` | Soria (headings) | [Bydani](https://www.behance.net/danibydani) | [CC BY-ND 4.0](https://creativecommons.org/licenses/by-nd/4.0/). Converted TTF → WOFF2, design unchanged |
| `inter-tight-*.woff2` | Inter Tight (text) | [The Inter Project Authors](https://github.com/rsms/inter-tight) | SIL OFL 1.1 |
| `ibm-plex-mono-*.woff2` | IBM Plex Mono (labels) | [IBM](https://github.com/IBM/plex) | SIL OFL 1.1 |

Full licence texts are in `licenses/`.
✏️ To swap the heading font: put the new .woff2 here and change the file name at the top of `assets/css/site.css` ([FONTS]).
